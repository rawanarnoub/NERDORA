# 🧠 NerdoRA

NerdoRA is an AI-powered study assistant built with Streamlit and Groq AI models.  
The app helps students learn smarter by explaining topics, solving exercises, generating flashcards, and creating AI-powered exams.

---

# ✨ Features

## 📘 Explain Topics
- Beginner-friendly explanations
- Simple summaries
- Step-by-step learning
- Examples and key concepts

## 🧮 Solve Exercises
- Step-by-step solutions
- Math, science, coding, and logic support
- Similar practice questions

## 🃏 Flashcard Generator
- AI-generated flashcards
- Interactive studying
- Revision mode
- Memory-based learning

## 📝 Exam Generator
- AI-created quizzes and exams
- Multiple choice questions
- Answer keys included
- Difficulty selection

# 🚀 Tech Stack
